# NutriCampus

Landing page responsive y demo interactiva de NutriCampus, alineada con los mockups Web/Móvil, Arquitectura, User Flows, Needfinding y la trazabilidad de 30 HU core.

## Archivos

- `index.html`: estructura accesible y puntos de montaje de las vistas.
- `styles.css`: estilos visuales y adaptación para desktop, tablet y móvil.
- `app.js`: navegación, filtros, formularios, detalles y estado local.
- `assets/`: imágenes de comida extraídas de los mockups entregados.
- `TRAZABILIDAD-HU.md`: relación de las 30 HU con la evidencia implementada y límites de la demo.

## Ejecutar

Abre `index.html` en un navegador moderno. La página no requiere servidor ni paquetes externos; la tipografía usa Google Fonts cuando hay conexión y cuenta con fuentes de respaldo.

## Publicación

Es un sitio estático y puede alojarse en GitHub Pages, Netlify, Vercel u otro hosting estático. La publicación no está configurada porque aún no se indicó un proveedor ni un repositorio/dominio destino.
